To make the shareable .exe (needs a Windows PC with Python from python.org):
  1. Double-click BUILD_EXE.bat
  2. Zip the new "CartridgeCalculator" folder and send it.
Your dad unzips it and double-clicks CartridgeCalculator.exe. Keep the .csv files beside the .exe.
(Windows may show a "protected your PC" warning for unsigned apps: More info > Run anyway.)
